# 긍정적 회고와 다음 날 자기효능감

대학생의 14일 일상기록을 위한 **문헌고찰 및 연구계획**을 웹 논문 형식으로 정리한 프로젝트입니다. 긍정적 회고가 다음 날의 상태 자기효능감과 어떻게 관련되는지 검토할 수 있도록 연구 질문, 측정 절차, 분석계획, 윤리 기준과 향후 앱 구현 요건을 제시합니다.

> 이 프로젝트는 실제 연구 결과를 보고하지 않습니다. 제시된 내용은 데이터 수집 전 단계의 문헌고찰과 재현 가능한 연구 프로토콜입니다.

## 바로 보기

- 웹사이트: [positive-reflection-research-paper.vercel.app](https://positive-reflection-research-paper.vercel.app/)
- 언어: 한국어 기본 · English 전환 지원

## 구성

- 연구 배경과 핵심 개념의 구분
- 감사·긍정심리중재 및 자기효능감 관련 선행연구 검토
- 14일 단일집단 반복측정 연구설계
- 측정도구, 데이터 관리, 혼합모형 분석계획
- 결과 보고의 투명성 및 참여자 보호 원칙
- 저위험 자기기록 앱 MVP로의 전환 설계
- 참고문헌과 재현 패키지 안내

## 주요 원칙

1. **과장하지 않습니다.** 관찰연구 설계로 확인 가능한 연관성과 실행 가능성만 다룹니다.
2. **개인정보를 최소화합니다.** 불필요한 식별정보와 원문 일기 공개를 피하는 방향을 제안합니다.
3. **재현 가능성을 우선합니다.** 데이터 사전, 코드북, 분석 스크립트, 변경 기록을 함께 제공하는 구조를 권장합니다.
4. **치료를 대체하지 않습니다.** 본 웹 논문과 제안 앱은 의료적 진단·치료·위기대응 서비스가 아닙니다.

## 로컬에서 열기

별도 설치 없이 `index.html` 파일을 브라우저로 열면 됩니다. 정적 HTML, CSS, JavaScript만으로 구성되어 있습니다.

```text
index.html   웹 논문 구조
style.css    반응형·인쇄용 스타일
script.js    한·영 전환 및 논문 콘텐츠
favicon.svg  사이트 아이콘
```

## 인용 및 참고

핵심 근거 문헌은 웹사이트의 참고문헌 장에서 DOI와 함께 확인할 수 있습니다. 대표적으로 Bandura (1997), Emmons & McCullough (2003), Fredrickson (2001), Seligman et al. (2005), Sin & Lyubomirsky (2009)의 연구를 검토했습니다.

## 라이선스와 사용

교육·연구·프로토타이핑 목적의 참고 자료입니다. 실제 참가자 데이터를 수집하거나 앱을 공개할 경우, 소속 기관의 연구윤리 심의와 개인정보 보호 요건을 별도로 검토해야 합니다.
